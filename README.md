## 2. Explain Generative AI Architectures, Focusing on Transformers

**Prompt:**

Explain the major Generative AI architectures, focusing on Transformers. Describe their components, working process, advantages, and limitations in simple language.

**Answer:**

Generative AI architecture refers to the structure of an AI model that learns patterns and generates new content. Major architectures include Transformers, GANs, VAEs, and Diffusion Models.

### Transformer Architecture

The Transformer architecture was introduced in the research paper *Attention Is All You Need* in 2017. It uses attention mechanisms to understand relationships between different parts of an input sequence.

### Main Components

1. **Tokenization:** Divides text into smaller units called tokens.
2. **Embeddings:** Converts tokens into numerical representations.
3. **Positional Information:** Helps the model understand the order of tokens.
4. **Self-Attention:** Identifies relationships between tokens and determines which information is important.
5. **Multi-Head Attention:** Examines different relationships in parallel.
6. **Feed-Forward Network:** Processes information to learn additional patterns.
7. **Output Layer:** Produces scores for possible next tokens.

### Working Process

The Transformer receives text and converts it into tokens. It processes the tokens using attention mechanisms and neural network layers. The model then predicts suitable output tokens.

For text generation, the model selects a token and repeats the process until the response is complete.

### Other Architectures

- **GANs:** Generate data through competition between a generator and discriminator.
- **VAEs:** Learn compact data representations and generate new samples.
- **Diffusion Models:** Generate content by gradually removing noise.

### Advantages and Limitations

Transformers can process context effectively, handle complex language tasks, and scale to large datasets. However, they require considerable computing resources and can generate incorrect information.

## 4. Explain the Impact of Scaling in Large Language Models (LLMs)

**Prompt:**

Explain how scaling affects Large Language Models. Include model size, training data, computing power, performance improvements, costs, challenges, and efficient scaling methods in simple language.

**Answer:**

Scaling in Large Language Models refers to increasing the model's size, training data, or computing resources to improve its capabilities.

### Factors Affecting Scaling

**1. Model Size**

Model size is commonly measured by the number of parameters. Parameters are values adjusted during training. Increasing the number of parameters can help a model learn more complex patterns, but it also increases memory and computing requirements.

**2. Training Data**

LLMs learn from large amounts of text and other data. High-quality and diverse data help models understand language and generate useful responses.

**3. Computing Power**

Training large models requires powerful hardware such as GPUs and AI accelerators. More computing resources can support larger training processes but increase costs and energy consumption.

### Impact of Scaling

Scaling can improve:

- Language understanding.
- Text generation.
- Instruction following.
- Code generation.
- Performance across multiple tasks.
- Learning from examples provided in prompts.

However, larger models do not automatically perform better on every task. Performance also depends on data quality, architecture, and training methods.

### Scaling Laws

Scaling laws describe relationships between model size, training data, computing resources, and model performance. In many settings, increasing these resources appropriately improves training results.

For example, a larger model trained with sufficient high-quality data may perform better than a smaller model on certain tasks.

### Challenges of Scaling

- High training and operating costs.
- Increased electricity consumption.
- Greater hardware requirements.
- Longer response times in some settings.
- Potential bias and inaccurate outputs.
- Difficulties in deploying models on smaller devices.

### Efficient Scaling Methods

- **Quantization:** Reduces the numerical precision used to represent model parameters.
- **Knowledge Distillation:** Transfers useful behaviour from a larger model to a smaller model.
- **Data Quality Improvement:** Uses more relevant and reliable training data.
- **Parameter-Efficient Fine-Tuning:** Updates a small portion of model parameters.
- **Mixture of Experts:** Activates selected model components for different inputs.

These techniques can reduce costs and improve efficiency while maintaining useful performance.

## 5. Explain Large Language Models (LLMs) and How They Are Built

**Prompt:**

Explain what a Large Language Model is and describe how it is built step by step, including data collection, preprocessing, tokenization, architecture, training, fine-tuning, evaluation, and deployment.

**Answer:**

A Large Language Model (LLM) is an AI model trained on large amounts of text and sometimes code or other data. It learns patterns in language and uses them to generate responses.

LLMs can answer questions, summarize documents, translate languages, write stories, and generate computer programs. Many modern LLMs use Transformer architectures.

### Steps to Build an LLM

**1. Define the Objective**

Determine the purpose of the model, such as answering questions, generating text, or assisting with programming.

**2. Collect Training Data**

Gather suitable data from sources such as books, articles, websites, licensed content, and programming code, depending on the intended use.

**3. Preprocess the Data**

Clean the data by removing duplicates, correcting formatting problems, and filtering unsuitable content. Privacy and copyright requirements must also be considered.

**4. Tokenization**

Divide text into smaller units called tokens and convert them into numerical token IDs.

**5. Select the Architecture**

Choose a suitable model architecture. Transformers are commonly used because their attention mechanisms help models learn relationships between tokens.

**6. Pretraining**

Train the model using a large dataset. A common method is next-token prediction, where the model learns to predict the next token in a sequence.

For example, given the text "The sky is", the model learns to predict likely next tokens based on its training.

The model adjusts its parameters repeatedly to improve its predictions.

**7. Fine-Tuning**

Train the pretrained model further using examples suited to its intended tasks. This can improve instruction following and response quality.

**8. Evaluation**

Test the model for accuracy, response quality, coding ability, bias, safety, and reliability. Both automated tests and human evaluation can be used.

**9. Deployment**

Make the model available through an application, website, API, or local system so users can interact with it.

**10. Maintenance**

Monitor the model's performance, fix problems, improve efficiency, and update the system when necessary.

### Applications of LLMs

- Education: Explaining lessons and preparing study materials.
- Business: Writing emails and reports.
- Programming: Generating code and identifying errors.
- Customer service: Answering common questions.
- Research: Summarizing documents and organizing information.

### Limitations

LLMs may produce incorrect information, reflect biases, require significant computing resources, and have limited knowledge of events beyond their available information. Therefore, their outputs should be verified when accuracy is important.

### 1. Foundational Concepts of Generative AI

**What is Generative AI?**
Generative AI is a type of AI that creates new content such as text, images, audio, video and code. It learns patterns from large amounts of data and then produces new content that looks similar.

**Generative vs Discriminative models**

**Main building blocks**

**Main types of generative models**
| Type | Idea | Output |
|------|------|--------|
| Autoregressive (GPT) | Predicts the next word/token | Text, code |
| VAE | Compresses data and rebuilds new samples | Images |
| GAN | Generator and discriminator compete | Realistic images |
| Diffusion | Removes noise step by step | Images, audio, video |

**How it works**
- *Training:* the model reads huge amounts of data and learns to predict the next piece (for example, the next word).
- *Generation:* given a prompt, it predicts one token at a time until the answer is complete.

**Limitations**
- Hallucination (confident but wrong answers)
- Bias from training data
- High compute and energy cost
- Copyright, privacy and misuse concerns (e.g., deepfakes)

### 2. Generative AI Architectures (Transformers)

**Why transformers?**
Introduced in the 2017 paper *"Attention Is All You Need"*, transformers process all words in parallel and understand long-range relationships using attention. They replaced RNNs and LSTMs.

**Self-attention**
Each word creates three vectors: Query (Q), Key (K) and Value (V).

```
Attention(Q, K, V) = softmax(Q·Kᵀ / √d_k) · V
```
This lets the model decide which words are important for understanding each other word. Example: in "The animal didn't cross the street because it was tired," attention links "it" to "animal."

**Multi-head attention**
Several attention operations run in parallel. Each head can focus on a different relationship (grammar, meaning, position).

**Positional encoding**
Attention does not know word order, so position information is added to each token (sinusoidal, learned, or RoPE).

**Transformer block**
1. Multi-head self-attention
2. Add & normalise
3. Feed-forward network
4. Add & normalise

Many such blocks are stacked to make the full model.

**Types of transformers**
| Type | Examples | Used for |
|------|----------|----------|
| Encoder-only | BERT | Classification, search |
| Decoder-only | GPT, LLaMA, Claude | Text and code generation |
| Encoder–decoder | T5, BART | Translation, summarisation |

**Comparison with other architectures**
| Architecture | Strength | Weakness |
|--------------|----------|----------|
| Transformer | Scales well, handles long context | Costly for very long inputs |
| GAN | Sharp images | Unstable training |
| VAE | Stable training | Blurry output |
| Diffusion | High quality, diverse | Slow generation |

### 4. Impact of Scaling in LLMs

**What is scaling?**
Increasing three things together:
- Model size (number of parameters)
- Training data (number of tokens)
- Compute (training power)

**Scaling laws**
- Kaplan et al. (2020) showed that error decreases smoothly as size, data and compute increase.
- The Chinchilla study (2022) showed that many models were under-trained. For best results, model size and data should grow together.

**Benefits**
- Higher accuracy and fluency
- Better reasoning, coding and instruction following
- Emergent abilities, such as in-context learning, appearing at larger scales
- Better support for many languages and multimodal inputs

**Challenges**
| Challenge | Meaning |
|-----------|---------|
| High training cost | Needs thousands of GPUs for weeks |
| High running cost | Bigger models are slower and costlier to serve |
| Energy use | Large carbon footprint |
| Data limits | Good quality data is limited |
| Diminishing returns | Each gain needs much more compute |
| Safety | More powerful models carry bigger risks |

**Beyond just making models bigger**
- Better and cleaner data
- Mixture-of-Experts (only part of the model runs per token)
- Quantisation and distillation to make models smaller
- Fine-tuning and RLHF for better behaviour
- Letting the model "think longer" at answer time
- Small language models that run on phones and laptops

### 5. What Is an LLM and How Is It Built?

**Definition**
A Large Language Model (LLM) is a neural network, usually a decoder-only transformer, trained on huge amounts of text to predict and generate language. It can answer questions, write, translate, summarise and code.

**Steps to build an LLM**

1. **Data collection:** gather text from websites, books, articles and code. Clean it by removing duplicates, low-quality and harmful content.
2. **Tokenization:** split text into small units (tokens) using methods like BPE, then convert them into numbers and embeddings.
3. **Model design:** choose a decoder-only transformer and set the number of layers, attention heads, hidden size and context length.
4. **Pre-training:** train the model to predict the next token over trillions of tokens, using many GPUs/TPUs for weeks or months.
5. **Fine-tuning:** train on instruction–response examples so the model follows user requests.
6. **Alignment:** use RLHF or DPO, where human preferences guide the model to be helpful, honest and safe.
7. **Evaluation:** test on benchmarks (knowledge, reasoning, coding) and do red-teaming to check safety.
8. **Deployment:** serve through APIs or apps, optimise speed with quantisation and caching, and keep monitoring.

**Pipeline in one line**
```
Data → Cleaning → Tokenization → Pre-training → Fine-tuning → Alignment → Evaluation → Deployment
```

**Key terms**
- **Parameters:** the learned weights of the model
- **Context window:** how much text the model can read at once
- **Temperature:** controls randomness of output
- **RAG:** retrieval-augmented generation, which uses external documents to ground answers
